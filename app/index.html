Cách lấy Gemini API key

Key là một chuỗi chữ giúp app nói chuyện với Google. Lấy miễn phí, không cần thẻ ngân hàng, mất khoảng 2 phút. Làm ngay trên điện thoại này.

1

Mở trang Google AI Studio

Bấm nút xanh "Mở trang lấy key" ở trên. Trang aistudio.google.com/apikey sẽ mở trong Chrome.

2

Đăng nhập Gmail cá nhân

Chọn tài khoản Gmail của bạn (dạng …@gmail.com). Không dùng email công ty, vì email công ty hay bị chặn tạo key.

3

Đồng ý điều khoản (chỉ lần đầu)

Lần đầu vào, trang sẽ hỏi bạn đồng ý điều khoản sử dụng. Đánh dấu ô đồng ý rồi bấm tiếp tục.

4

Bấm "Create API key"

Tìm nút Create API key (tiếng Việt: Tạo khóa API). Trên điện thoại, có thể phải mở menu ☰ ở góc trái rồi chọn mục Get API key trước.

5

Chọn tạo trong dự án mới

Nếu hiện bảng hỏi chọn dự án, chọn Create API key in new project (Tạo trong dự án mới). Chờ vài giây để Google tạo key.

6

Sao chép key

Key hiện ra là một chuỗi dài bắt đầu bằng AIza. Bấm biểu tượng sao chép (hai ô vuông chồng nhau) hoặc nút Copy.

7

Quay lại app và dán key

Mở lại app Luyện nói → Cài đặt. Chạm và giữ vào ô key, chọn Dán, rồi bấm Lưu. Xong. Chạm nút tròn để bắt đầu nói.

Nếu app báo lỗi

  • Lỗi về key hoặc "API key not valid": sao chép lại key, chú ý không thừa dấu cách ở đầu hay cuối.
  • Key ghi "Unrestricted" (không giới hạn): trên trang API Keys, chạm vào nhãn đó, chọn Add restrictions → Restrict to Gemini API only. Key cũ không giới hạn có thể bị Google từ chối.
  • Lỗi mô hình hoặc hết hạn mức (429): vào Cài đặt, đổi sang mô hình khác trong danh sách, hoặc chờ vài phút.
  • Không thấy nút Create API key: đổi sang Gmail cá nhân khác, vì một số tài khoản tổ chức bị khóa tính năng này.

Giữ key an toàn

  • Key giống như mật khẩu: không gửi cho người khác, không đăng lên mạng.
  • Nếu lỡ để lộ, vào trang API Keys xóa key cũ và tạo key mới.

Cài đặt

Chưa có key? Bấm "Xem hướng dẫn". Key chỉ lưu trên điện thoại này.
Nếu kết nối báo lỗi mô hình hoặc hết hạn mức miễn phí, thử mô hình khác trong danh sách.
App có thể tự điều chỉnh mức sau mỗi buổi.
Người mới cần thời gian nghĩ: 1500–2000 ms. Giảm nếu thấy app phản hồi chậm.
